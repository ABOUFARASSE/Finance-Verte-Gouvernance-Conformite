Module 10 · Évaluation finale

QCM : gouvernance et conformité en finance durable

20 questions · Note sur 20 · Jusqu’à trois tentatives · Meilleur score retenu

Modalités

La banque contient 80 questions de repérage simple et 20 questions de compréhension. Votre tirage comprend 16 questions simples puis 4 de compréhension, soit quatre questions simples et une de compréhension pour chacune des quatre séances. Chaque question propose quatre réponses et une seule est correcte. Une bonne réponse vaut un point ; une erreur ou une absence de réponse vaut zéro, sans pénalité.

Une tentative est décomptée lorsque vous la commencez. Vous pouvez la reprendre avec le même code tant qu’elle n’est pas validée. La validation est définitive et affiche le corrigé détaillé des 20 questions. Le meilleur des scores validés est conservé, avec un maximum de trois tentatives commencées.

Les questions peuvent réapparaître lors d’un autre tirage. Il n’y a pas de chronomètre imposé. Utilisez uniquement le code individuel remis par l’enseignant ; conservez-le pour retrouver vos résultats.

Accès individuel

Ce nom sera associé à votre code dès la première tentative.

Les nouvelles tentatives sont actuellement fermées.
