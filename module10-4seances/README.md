# Module 10 — Parcours en quatre séances de trois heures

Version autonome, accessible sous `/module10-4seances/`. Les six blocs du cours existant sont conservés dans `contenus/` et regroupés en quatre parcours de 180 minutes. Les fichiers sources de l’ancienne version restent inchangés.

Le QCM utilise l’API `module10-qcm-v2` du projet Supabase Finance-Verte-Evaluation. Tirage côté serveur : 5 questions par séance, 20 au total ; 3 tentatives maximum par code individuel ; meilleure note validée retenue. Les réponses correctes et les codes ne sont pas publiés dans ce dépôt. Les corrigés ne sont transmis qu’après validation de la tentative.

Les scripts `backend/` décrivent le schéma et le handler, sans clé ni banque de réponses. Les droits SQL sont limités au rôle serveur ; aucune lecture anonyme des questions ni des résultats. Les codes d’accès et la clé enseignant sont transmis séparément dans le dossier enseignant.
