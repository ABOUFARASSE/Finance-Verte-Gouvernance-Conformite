Comment travailler

Lire la question initiale, étudier les concepts, refaire les calculs puis ouvrir les corrections. Utiliser les laboratoires pour tester une hypothèse et expliquer le mécanisme qui change le résultat. Les corrigés sont accessibles librement pour l’apprentissage. Les polycopiés et leurs sources LaTeX sont disponibles dans chaque séance.

Les CSV s’importent dans Excel avec le séparateur point-virgule et le point comme séparateur décimal d’origine. Le code Python du modèle et les résultats JSON permettent de reproduire les calculs sans dépendance externe.
